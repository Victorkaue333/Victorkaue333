# Como instalar

Copie estes arquivos para o repositório de perfil `Victorkaue333/Victorkaue333`:

```text
README.md
assets/
  hero-matrix.svg
  profile-card.svg
  projects.svg
.github/
  workflows/
    snake.yml
```

Depois:

1. Faça commit de todos os arquivos.
2. Abra a aba **Actions** do repositório.
3. Execute manualmente o workflow **Generate contribution snake** uma vez.
4. Aguarde a criação da branch `output`.
5. Recarregue o perfil.

A animação do Snake passará a ser atualizada automaticamente uma vez por dia.
